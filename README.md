# Hanuman Enterprises Security Systems

A premium, modern, and highly responsive React e-commerce platform for CCTV & Security Systems. 

## 🚀 Features
- **Modern E-Commerce UI:** A stunning, animated, and responsive user interface built from the ground up to provide a premium shopping experience.
- **Dedicated Brand Pages:** Browse products from top security brands like CP PLUS, Hikvision, Dahua, Axis, EZVIZ, and TP-Link in their own dedicated showcases.
- **Dynamic Product Pages:** Detailed specifications, 360-degree image views, and dynamic cart integration.
- **Smart Recommendations:** An Amazon-style "Similar Products" recommendation engine built into every product page.
- **Global Cart State:** A fully robust shopping cart system with quantity management and a streamlined "Request a Quote" checkout flow.
- **Live Search:** Instant search functionality filtering through names, models, brands, and tags.
- **Admin Portal:** Manage products and track orders through a secure dashboard interface.

## 🛠 Tech Stack
- **Frontend Framework:** React (Vite)
- **Styling:** Custom CSS (index.css) utilizing advanced Flexbox and CSS Grid
- **State Management:** React Context API (`CartContext`)
- **Routing:** Hash-based client-side routing

## 📦 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/avinashbasani132/hanuman-security-systems.git
   ```
2. Navigate into the directory:
   ```bash
   cd hanuman-security-systems
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

### Running Locally
Start the development server:
```bash
npm run dev
```
The application will be available at `http://localhost:5173`.

### Building for Production
To generate a production-ready build:
```bash
npm run build
```
The optimized bundle will be available in the `dist` folder.
